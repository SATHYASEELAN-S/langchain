# LangChain Course - Day 1 Notes

## What I learned today

Today I set up a Python project using uv and added the first dependencies for LangChain development.

## Steps I completed

1. Installed uv.
2. Initialized the project: uv init
3. Added LangChain: uv add langchain
4. Added dependencies: uv add python-dotenv black isort

## Current project setup

- Python version: >=3.12
- Project name: langchain-course
- Dependencies: langchain, python-dotenv, black, isort

## Notes

- python-dotenv loads environment variables from .env.
- black formats code.
- isort organizes imports.
